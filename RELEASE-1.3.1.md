# Полянка 1.3.1 — восстановление иллюстраций и импорт расписания

- Возвращены прежние встроенные иллюстрации по умолчанию в шапке, меню и списке покупок; для каждого слота доступны ещё три локальных варианта в прежнем пиксельном стиле. Загрузка пользовательских картинок не добавлялась.
- Фон интерфейса и светлые поверхности сделаны менее яркими, с более приглушёнными природными оттенками.
- Исправлены карточки коллекции: оборот показывает способ приготовления, карточка возвращается на лицевую сторону повторным нажатием.
- В форму импорта восстановлена информационная кнопка с полным промтом для внешнего ИИ; сайт сам не генерирует рецепты, а текст промта не включается в копируемый YAML распаковщика.
- Уточнён AI-промт: даты для автодобавления меню выводятся только в поле «В меню» в строках ISO `ГГГГ-ММ-ДД | порции`; неоднозначные даты не угадываются.
- Парсер расписания принимает ISO и однозначные даты `ДД.ММ.ГГГГ`, десятичные порции и распространённые разделители, валидирует календарную дату и отклоняет неоднозначный текст.
- Добавлены unit и UI регрессии для расписания, карточек коллекции и встроенного арта.

Проверки: `npm test`, `npm run typecheck`, `npm run build`, `npm run test:ui`.

Схема БД не менялась. Архив исключает `node_modules`, `.next`, тестовые артефакты и секретные `.env`.
