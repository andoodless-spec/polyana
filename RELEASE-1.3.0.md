# Полянка 1.3.0 — обновление интерфейса и импорта меню

- Веб-иконка выбирается в персонализации; четыре встроенных пиксельных варианта.
- По четыре локальные иллюстрации в едином стиле для шапки, меню и листа покупок; сторонние загрузки в этих слотах выключены.
- Способ приготовления находится на обороте карточки блюда; повторное действие возвращает к лицевой стороне. Рецепт можно вручную создать или редактировать в редакторе.
- Увеличен набор уникальных пиксельных изображений для типов продуктов холодильника.
- Обновлён отдельный внешний AI prompt `AI-MENU-PROMPT.txt`: сырой вес овощей/мяса, сухой вес круп; обычные названия без «сырой/сухой/готовый»; масло для жарки не включать; красный вместо репчатого лука; «п.в.» для приправ по вкусу и подходящих компонентов салата.
- Импорт обрабатывает `п.в.`, десятичную запятую и простую Markdown-разметку, не импортирует внешнее резюме стоимости как ещё одно блюдо.
- Обновлены unit/UI проверки. `npm test`, `npm run typecheck`, `npm run build`, `npm run test:ui` прошли.

Схема БД и серверные таблицы не менялись. ZIP исключает `.env` (включая `.env.example` допустим только как пример), `node_modules`, `.next` и локальные артефакты тестов.
