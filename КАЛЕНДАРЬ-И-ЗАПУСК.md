# Полянка — календарь и запуск

В проект добавлен календарь с сезонными шапками, мини-виджетом на главной, заметками и ежегодным повторением, циклом рабочих смен 2/2, ручной настройкой смен, днями рождения с выбранным цветом шарика, стикерами без контура, ссылками на меню и список продуктов, отдельным светлым/тёмным оформлением и экспортом месяца в PNG.

Меню и список продуктов автоматически переходят с одной колонки на две при большом количестве содержимого и возвращаются к одной колонке на узком экране. Сохранённая тема сайта задаёт цветовую палитру календаря.

## Запуск

Требуется Node.js версии 20.9 или новее.

1. Распакуйте архив проекта.
2. Откройте терминал в папке проекта.
3. Выполните `npm install`.
4. Для локального запуска выполните `npm run dev` и откройте адрес, указанный в терминале.
5. Для проверки production-сборки выполните `npm run build`, затем `npm start`.

`npm run typecheck` проверяет типы, а `npm test` запускает быстрые модульные тесты. Для сохранения данных, синхронизации и авторизации могут понадобиться параметры окружения из `.env.example`.
