# Полянка 1.3.2 — единый период меню и удобный экспорт

- Меню имеет общий диапазон «с… по…», не распределяется по дням и сортирует блюда по категориям: салаты, супы, горячее, закуски.
- Число порций блюда определяет видимые количества ингредиентов и расчёт покупок.
- Копирование промта доступно по кнопке-листочку, встроенный промт в интерфейсе не раскрывается.
- Арт фиксирован на встроенных вариантах; пользовательская загрузка и выбор удалены.
- Список домашних запасов снова обычный текстовый список.
- Рецепт открывается нажатием на название; возврат к названию — нажатием на рецепт.
- Управление позициями меню включается кнопкой «Редактировать».
- PNG меню и покупок рендерятся отдельно от интерфейса; в браузере поддерживается системное меню передачи файла.
- Для меню и покупок вода исключена; в промте она разрешена только в приготовлении.

Проверки: `npm test`, `npm run typecheck`, `npm run build`, `npm run test:ui`.

Архив исключает зависимости/кеши и секретные `.env`. Загрузка ZIP или просмотр локального preview сами по себе не публикуют production.
